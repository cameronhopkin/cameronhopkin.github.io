# Tyrminal

Personal blog. Faith, fitness, tech.

**Live at:** https://tyrminal.com

## Local Dev

```bash
hugo server -D
```

## New Post

```bash
# General post
hugo new posts/my-post.md

# Faith
hugo new faith/my-post.md

# Tech
hugo new tech/my-post.md

# Fitness
hugo new fitness/my-post.md
```

Set `draft: false` when ready to publish.

## Deploy

Push to `main`.
